Genre templates for the spatial mix plan (decision 0017). One JSON file per genre: objects
(where each part of each stem goes, how wide, how far, how much room, whether and how it moves),
the surround and height bed, and how much the scene opens per section. Each entry carries its
reasoning in `why`. `audioset` lists the AudioSet labels that map to the template when the tagger
picks the genre; the listener can always override it.
